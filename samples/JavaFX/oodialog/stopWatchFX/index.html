.. <directory> (List of parent directory)
Display all of the parent directory's files and directories.
main.rex
The main Rexx program that sets up and starts the JavaFX application. This program will cause JavaFX to load and process the GUI defined in the XML text file of "stopWatchFX.fxml".
stopWatchFX.fxml
The XML text file that defines the GUI, runs the Rexx program "stopWatchFXController.rex" and defines an event handler, programmed in Rexx.
stopWatchFXController.rex
A Rexx package defining a public routine that gets invoked by the Rexx event handler defined in "stopWatchFX.fxml"

testAddManyNetRexxCommandHandlers.rex
A Rexx demonstration program to show how to add and use Rexx command handlers implemented in NetRexx (Java).

The companion NetRexx program (implementing the Rexx command handlers) is: NetRexxCommandHandlers.nrx. This NetRexx program defines eleven different Rexx command handler classes! They demonstrate among other things how to set context Rexx variables, raise Rexx conditions and Rexx exceptions from the NetRexx (Java) handler code.

To compile the NetRexx program enter the following command on the command line:

    nrc -compile NetRexxCommandHandlers.nrx

To run enter the following command on the command line:

    rexx testAddManyNetRexxCommandHandlers

RunRexxWith_RXMSQ_Exit.rex
An ooRexx demonstration program to show, how easy it is to invoke a Rexx program for which a Rexx RXMSQ exit handler got implemented in ooRexx using BSF4ooRexx850.

The companion Rexx program is: testRexxWith_RXMSQ_Exit.rxj.

To run enter the following command on the command line:

    rexx RunRexxWith_RXMSQ_Exit.rex

JavaRunRexxWith_RXTRC_Exit.java
A Java demonstration program to show, how easy it is to invoke a Rexx program for which a Rexx RXTRC exit handler got implemented in Java.

The companion Rexx program is: testRexxWith_RXTRC_Exit.rxj.

To run enter the following command on the command line:

    java JavaRunRexxWith_RXTRC_Exit

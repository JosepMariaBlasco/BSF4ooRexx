This subdirectory contains nutshell examples for remote-controlling/automating/scripting
OpenOffice (cf. http://www.OpenOffice.org) and Sun's commercial counterpart: StarOffice.

These examples are excerpted from two papers produced by students at the Wirtschaftsuniversität
Wien (WU, http://www.wu-wien.ac.at/english).


Ahammer, Andreas (November 2005):

        Nuthsell examples to drive OpenOffice.org by ooRexx in a Platform independent manner
        ------------------------------------------------------------------------------------

        This directory contains slightly edited examples by Andreas Ahammer, who documented them
        in his work <http://wi.wu-wien.ac.at/rgf/diplomarbeiten/index.html#bakk_07>.

        Just run each example and look at its code. If you wish to run the examples consecutively,
        you can start them by running "rexx all.rxjo".

        All scripts (except for the MS Access example) should run on Linux and Windows (and other
        operating system platforms).

        Rony G. Flatscher

        2006-01-17, Wirtschaftsuniversitaet Wien, Vienna, Austria

Burger, Martin (May 2006):

        Nuthsell examples to drive OpenOffice.org by ooRexx in a Platform independent manner
        ------------------------------------------------------------------------------------

        This directory contains the nutshell examples by Martin Burger, who documented them
        in his work <http://wi.wu-wien.ac.at/rgf/diplomarbeiten/index.html#bakk_200601>.

        All scripts (except for the MS InternetExplorer example) should run on Linux and Windows
        (and other operating system platforms).

        Rony G. Flatscher

        2006-05-29, Wirtschaftsuniversitaet Wien, Vienna, Austria

        P.S.: These samples are meant to be started as ooRexx macros from *within* OpenOffice/StarOffice.


Both works have been carried out with an incredible amount of participation and effort on the
side of the students. Therefore the reader is able to take advantage of their work and by comparison
"jump-start" scripting OpenOffice/StarOffice in a platform independent manner.

2006-05-29, WU Wien, Rony G. Flatscher

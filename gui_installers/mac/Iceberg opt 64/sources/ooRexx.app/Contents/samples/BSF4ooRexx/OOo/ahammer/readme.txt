Nutshell examples to drive OpenOffice.org by ooRexx in a Platform independent manner
------------------------------------------------------------------------------------

This directory contains examples by Andreas Ahammer, who documented them in his work
<http://wi.wu-wien.ac.at/rgf/diplomarbeiten/index.htm#bakk_07> and which have been
edited, sometimes extended/updated by Rony G. Flatscher.

All scripts (except for the MS Access example) should run on Linux and Windows (and other
operating system platforms).

To run all scripts invoke 'runAllExamples.cmd' (Windows) or 'runAllExamples.sh' (Unix).

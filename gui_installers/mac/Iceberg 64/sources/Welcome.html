Welcome to the Installer for ooRexx with BSF4ooRexx!



This wizard will install ooRexx and BSF4ooRexx on your computer.


NOTE: If you have OpenOffice 3.3.0 (or higher) and/or LibreOffice 3.3.2 (or higher) installed on your system, this installer will automatically add BSF4ooRexx support for OpenOffice/LibreOffice. If OpenOffice/LibreOffice is installed later, the support can be added by invoking "Reinstall ooRexx with BSF4ooRexx" from the ooRexx menu bar.

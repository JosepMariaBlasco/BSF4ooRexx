This directory contains some information and links that may be useful for researching
some of the BSF4ooRexx supplied technologies, including a brief introduction into
ooRexx!

Article briefly introducing the concepts of ooRexx (including its history), presentation
given for the workshop "Revival of Dynamic Languages (RDL)" at the European Conference on
Object-Oriented Programming (ECOOP) in 2006: <http://wi.wu.ac.at/rgf/rexx/misc/ecoop06/>

        ECOOP2006_RDL_Workshop_Flatscher_Paper.pdf

From the 20th International Rexx Symposium (2009): <http://wi.wu.ac.at/rgf/rexx/orx20/>

        2009_orx20_BSF4Rexx-20091031-article.pdf  (New features yielding "BSF4ooRexx")

        2009_orx20_RGF_UTIL2-20100806-article.pdf (Utility package accompanying BSF4ooRexx)
        2009_orx20_RGF_UITL2-20110608-refcard.pdf

From the 21st International Rexx Symposiuim (2012):

        201202-CreatingOoRexxInterpreterInstances-article.pdf (new features for Java programmers)

Adding (2016-08-14, rgf) the documentation (Javadocs) for the datergf-package which is
distributed with BSF4ooRexx and used by "samples/1-050_DateRgf.rxj" and
"samples/1-060_DateRgfSample.rxj", just point your browser to

        datergf.doc/index.html

Starting with 2016-08-14, the following two Bachelor thesis explain and demonstrate
the support for .NET/CLR (Common Language Runtime) on the Windows version of BSF4ooRexx:

        20150810_Raffel-Manuel-ooRexx-Net-architecture.pdf
        20160723_Baginski-Adrian-ooRexx-Net-Cookbook.pdf

To learn about the installation possibilities (32-bit vs. 64-bit on Windows, Linux and MacOSX),
view the following file in your browser:

        installation/0_startHere.html

Starting with 2016-08-15, the Javadocs for Apache's BSF and BSF4ooRexx can be found:

        docs.apache.bsf/index.html
        docs.bsf4oorexx/index.html

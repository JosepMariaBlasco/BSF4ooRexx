Install BSF4ooRexx on Linux 64-bit

Java is a prerequisite for installing BSF4ooRexx. Java's and ooRexx's bitness must match (i.e. both must be 32 bit or both must be 64 bit)

First, check if you have either Java, ooRexx or both installed already.

Java
  • Open a terminal window (how?)
  • Enter "java -version"
  • If the output contains information about your java version, java is installed. If the information contains "64-Bit", you have java 64-bit installed. If it does not, you have java 32-bit installed.
    If the output does not contain information about your java version, java is not installed
ooRexx
  • Open a terminal window (how?)
  • Enter "rexx -v". If ooRexx is installed, some information about the installed version will be displayed (you will also see if you have the 32 or 64 bit version installed). Otherwise it is not installed

Java

Install Java

  1. Download Java (check the table above to see if you need 32 or 64 bit)
    32-bit: http://www.google.com/search?q=download java 32 bit linux
    64-bit: http://www.google.com/search?q=download java 64 bit linux
  2. Install Java

ooRexx

Install ooRexx

  1. Visit https://sourceforge.net/projects/oorexx/files/oorexx/
  2. Choose the newest ooRexx version (as of July 2016: 4.2.0)
  3. Download the newest version for your operating system (check the table above to see if you need 32 or 64 bit)
    32-bit (having "i386" in its name): as of July 2016, running Ubuntu: ooRexx-4.2.0-1.ubuntu1310.i386.deb
    64-bit (having "x86" in its name): as of July 2016, running Ubuntu: ooRexx-4.2.0-1.ubuntu1310.x86_64.deb
  4. Execute the downloaded file
  5. Go through the screens

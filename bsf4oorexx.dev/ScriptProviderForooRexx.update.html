New Version of the ooRexx Script Provider for OpenOffice.org

This document is created for OpenOffice.org (OOo) users of the ooRexx Script Provider in the case that it got updated.

The OOo update information that OOo meant to use gets stored in: ooRexx4OOo_update.xml.

Download Directions

Download the zip-archive named BSF4ooRexx_install.zip (show directory with all files).

Update Instructions

First you need to uninistall the OOo and BSF support for ooRexx, followed by unzipping BSF4ooRexx_install.zip and copying the subdirectry tree named "bsf4oorexx" over the existing subdirectory "bsf4oorexx", running rexx setupBSF.rex and rexx setupOOo.rex, followed by running the created installation programs (in that order) as super user/Administrator.

Uninstalling Currently Installed BSF4ooRexx

Find the directory "bsf4oorexx\install" (Windows) or "bsf4oorexx/install" (Linux) and run the following programs in the following order:

  • uninstallOOo_runAsAdministrator.cmd (Windows) or
    uninstallOOo_sudo.sh (Unix),
  • uninstallBSF_runAsAdministrator.cmd (Windows) or
    uninstallBSF_sudo.sh (Unix).

Installing New Version of BSF4ooRexx Containing the New ooRexx ScriptProvider Version forOOo

  • Download the latest version of BSF4ooRexx_install.zip and save it locally.

  • Uninstall the zip archive named "BSF4ooRexx_install.zip" which will create a subdirectory named "bsf4oorexx" containing numerous files and subdirectories. One of these subdirectories is named "install" into which you need to change to.

  • Run the programs (in that order):
    rexx setupBSF.rex (Windows),
    setupBSF_sudo.sh (Unix),
    and
    rexx setupOOo.rex (Windows),
    setupOOo_sudo.sh (Unix).

    These programs create installation and uninstallation scripts tailored to your system's need.

  • Run the generated installation scripts (in that order):
    • installBSF_runAsAdministrator.cmd (Windows) or
      installBSF_sudo.sh (Unix).
    • installOOo_runAsAdministrator.cmd (Windows) or
      installOOo_sudo.sh (Unix),

Further Help

The OOo update information is stored in: OOo.update.xml.

Use the OOo mailing lists, which are located in the developer area of http://www.OpenOffice.org.

If you have questions ad ooRexx and/or BSF4ooRexx then consult news:comp.lang.rexx, http://www.RexxLA.org, http://www.ooRexx.org.

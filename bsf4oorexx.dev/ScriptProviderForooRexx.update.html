New Version of the ooRexx Script Provider for OpenOffice.org

This document is created for OpenOffice.org (OOo) users of the ooRexx Script Provider in the case that it got updated.

The OOo update information that OOo meant to use gets stored in: ooRexx4OOo_update.xml.

Download Directions

Download the zip-archive for your system from https://sourceforge.net/projects/bsf4oorexx/files/GA/. "GA" is the acronym for "general availability", i.e. release software. Pick the subdirectory with the latest date.

Update Instructions

First you need to uninstall the OOo and BSF support for ooRexx, followed by installing the latest package from the above download.

Uninstalling Currently Installed BSF4ooRexx

Go to the BSF4ooRexx menu and choose Installatin and the option Uninstall BSF4ooRexx.

Installing Latest Version

  • Download the latest version for your system from https://sourceforge.net/projects/bsf4oorexx/files/GA/.
    • MacOS X: download the package, in the MacOSX Download folder open the installation volume, hover mouse over install icon, klick the right mouse button (!) and chose open and install.

    • Windows, AIX, Linux:
      download BSF4ooRexx_install.zip,
      unzip the archive,
      change into the install folder and pick next the folder named after your operating system,
      double-click on the file named install.cmd or install.sh

Further Help

The OOo update information is stored in: ScriptProviderForooRexx.update.xml.

Use the OOo mailing lists, which are located in the developer area of http://www.OpenOffice.org.

If you have questions ad ooRexx and/or BSF4ooRexx then consult http://www.RexxLA.org, news:comp.lang.rexx, http://www.ooRexx.org.

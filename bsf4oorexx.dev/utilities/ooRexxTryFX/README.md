# About ooRexxTryFx
## General
Author: Adrian Baginski
Date: 2017-12-03
Version: 1.00

## Purpose
This application provides a JavaFX driven playground for ooRexx programmers. It allows Rexx programs to be executed within the bounds of this application and integrates Syntax Highlighting for ooRexx.

## Features
**ooRexx Syntax Highlighting** after downloading the necessary files in the preference
A **File Tree** for easy file handling
**Two designes**, a dark and a bright one
**Preferences** to change font size, window maximization and other settings
